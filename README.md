# Calculadora de Daño Pokémon

Una aplicación Android para calcular el daño de los movimientos de Pokémon, diseñada para jugadores competitivos y entrenadores que quieren simular batallas con precisión.

## Características

- Cálculo exacto de daño, con resultados que coinciden con Pokémon Showdown.
- Soporte para todos los climas: Sol, Lluvia, Tormenta de Arena, Nieve, Sol Abrasador, Diluvio y Turbulencias.
- Soporte para todos los campos de batalla: Eléctrico, Hierba, Niebla y Psíquico.
- Cálculo de daño normal, crítico y porcentaje de vida.
- Interfaz intuitiva y modo oscuro.

## Cómo usar

1. Descarga el APK desde la sección de [Releases](https://github.com/Ramses063/CalculadoraDeDanoPokemon/releases).
2. Instálalo en tu dispositivo Android.
3. Introduce los datos de los Pokémon y el movimiento.
4. Pulsa "Calcular" para ver el resultado.
